# Customer Sentiment & Topic Analysis

An end-to-end NLP pipeline in Python using VADER sentiment analysis and LDA (Latent Dirichlet Allocation) topic modeling to analyze unstructured customer reviews and extract key operational insights.

---

## 📌 Project Overview
This project provides a comprehensive data-driven approach to understanding customer feedback. By combining lexicon-based sentiment classification with unsupervised topic modeling, it categorizes customer sentiment and uncovers underlying themes across review datasets.

---

## 🛠️ Key Features
- **Data Preprocessing & Cleaning:** Text normalization, noise removal, tokenization, and stop-word elimination.
- **Sentiment Analysis:** Categorizes reviews (Positive, Neutral, Negative) using **VADER** (Valence Aware Dictionary and sEntiment Reasoner).
- **Topic Modeling:** Extracts hidden themes and customer concerns using **LDA (Latent Dirichlet Allocation)**.
- **Data Visualization:** Distribution plots and visualizations using `matplotlib` and `seaborn`.

---

## 💻 Tech Stack & Libraries
- **Language:** Python 3.x
- **Data Manipulation:** `pandas`, `numpy`
- **Natural Language Processing:** `nltk`, `gensim`, `spacy`
- **Data Visualization:** `matplotlib`, `seaborn`
- **Environment:** Jupyter Notebook / Anaconda

---

## 📊 Dataset
The pipeline expects a structured review dataset (e.g., CSV) containing customer review texts and relevant metadata.
